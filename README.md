# College Clinic Appointment System

A simple Python-based appointment system for managing student visits to a college clinic.

## Features

* View doctor consultation fees
* Book clinic appointments
* Generate appointment token numbers
* Enter student name and department
* Choose between General and Specialist doctors
* Maximum of 10 appointments
* Calculate total number of students
* Calculate total consultation fees
* Display a message when the clinic is crowded

## Doctor Fees

| Doctor Type       |  Fee |
| ----------------- | ---: |
| General Doctor    | ₹100 |
| Specialist Doctor | ₹200 |

## How It Works

1. The user selects an option from the clinic menu.
2. The fee details for General and Specialist doctors can be viewed.
3. When making appointments, the user enters the number of students visiting.
4. For each student, the program takes:

   * Name
   * Department
   * Doctor type
5. A token number is assigned to each appointment.
6. The consultation fee is calculated based on the selected doctor.
7. The program displays the total number of students and total fees.
8. If more than 10 appointments are attempted, the clinic displays a crowded message.
